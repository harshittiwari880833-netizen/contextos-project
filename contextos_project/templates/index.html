What “automatic transfer” means

This app can import an export file and prepare a reusable context pack. It cannot automatically read your ChatGPT account or continuously sync new chats to Gemini. That would require supported, authorized integrations from both services. For now, you review the suggestions, download the pack, and provide it to Gemini yourself.

Only import data you are comfortable processing locally, and review/remove sensitive details before sharing.
